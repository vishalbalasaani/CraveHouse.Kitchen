# 🍰 Crave House – Premium Cloud Kitchen Website

A modern, premium, and fully responsive cloud kitchen website built for **Crave House**, an eggless dessert and drinks brand focused on satisfying cravings with luxury dessert bowls and handcrafted beverages.

The website is designed with a clean modern UI, aesthetic typography, smooth animations, and conversion-focused ordering experience for food lovers.

---

## ✨ Features

* Premium modern dark/light UI
* Fully responsive design
* Smooth scroll animations
* Hover interactions and transitions
* Interactive menu filtering system
* WhatsApp ordering integration
* Swiggy & Zomato ordering buttons
* Customer reviews section
* Premium hero section
* Floating WhatsApp support button
* Mobile-first layout
* Fast and lightweight performance
* Clean and reusable code structure

---

## 🍫 Menu Categories

### Cake Bowls

Premium eggless dessert bowls with rich flavors and creamy textures.

### Drinks

Refreshing handcrafted beverages designed to complement dessert cravings.

## 📱 Ordering Platforms

Customers can directly order through:
